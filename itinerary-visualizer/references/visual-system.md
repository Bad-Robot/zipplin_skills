# 默认视觉规范（2026-09-13 校准）

以用户确认的呼伦贝尔参考页与大连／沈阳修订页为视觉基线。通用样式集中在 `assets/itinerary-style.css`，生成器内联该文件；不要为每次行程另写一套页面或复制旅行专属补丁。

| 维度 | 旧输出问题 | 当前默认要求 |
|---|---|---|
| 地图 | 纸张网格上只有路线 | 真实海岸、河流、道路、绿地和地名，再叠加纸感配色 |
| 手绘效果 | 把地理信息和照片都变成插图 | 只处理地图显示风格，小插图只放地图装饰层 |
| 页首 | 墨绿大号衬线标题、过多留白 | 紧凑橙红渐变页首、白字、系统中文字体、小徽章 |
| 页面 | 双栏正文、松散布局 | 米色底、900px 内容宽、白色单列日程卡 |
| 图集 | 桌面四列、手机两列；SVG 兜底 | 正文实景照片，所有屏宽保持一行，超宽横滑 |
| 交互 | 只有缩放高亮 | 按天地图、原始底图切换、地名跳转、灯箱来源 |
| 可信度 | 没有比例尺、缺底图也交付 | 注册底图与路线、比例尺、来源署名、正式构建检查 |

## 样式参数

- 页面背景 `#fdf6e3`；页首 `#d35400 → #c0392b`；正文 `#2c3e50`；次级文字 `#5d6d7e`；住宿 `#2874a6`。
- 页首标题桌面 26px、手机 20px；日标题桌面 18px、手机 16px。
- 卡片圆角 12px；卡片间距约 14px；正文单列时间轴，辅助信息在其后。
- 图集放时间轴之前；`display:flex; flex-wrap:nowrap; overflow-x:auto`。缩略图 4:3，桌面最小宽 140px、手机 102px。禁止图片滤镜和插画替代。
- 首屏完整显示 4:3 地图；吸顶高度 `min(66.6667vw,62vh)`，手机上限 58vh。地图与卡片宽度分别管理。
- 普通滚轮滚动页面；Ctrl/Meta + 滚轮缩放地图。点地名跳转时间轴，键盘 Enter/空格同样可用。
- 打印展示逐日地图与图集，不保留吸顶控件。

## 地图层级

真实底图 → 仅颜色变换／纸纹 → 少量边缘意象 → 路线白色衬底 → 真实路线 → 距离标签 → POI／蓝色住宿 → 比例尺、指北针与署名。

不允许位移滤镜改变路线或海岸位置。地图装饰不得遮挡关键道路、海岸、河流与地点。切换日期必须更新相应范围的底图，不能只在全国尺度上放大路线。需对标签重叠进行浏览器视觉检查，必要时调整标签偏移而非地点坐标。
